# 环境变量与服务准备

克隆项目后，需要准备三件东西才能跑起来：**一个 `.env` 文件**、**三个数据库**、**一个模型 Key**。

`.env` 文件不会被提交到仓库（已在 `.gitignore` 里），项目根目录提供了模板 `.env.example`。

```bash
copy .env.example .env
```

## 二、逐个服务准备

### 1. MySQL（业务库）

必须建库并有以下 7 张表。字段名必须一致 —— 代码虽然做了列名探测，
但表结构差异过大仍会导致查询失败。

```sql
CREATE DATABASE IF NOT EXISTS order_customer_service
  DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_general_ci;
USE order_customer_service;

-- 登录用
CREATE TABLE users (
  user_id  BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  email    VARCHAR(120) NOT NULL UNIQUE,
  name     VARCHAR(50)  DEFAULT NULL
);

CREATE TABLE orders (
  order_id     BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  user_id      BIGINT UNSIGNED NOT NULL,
  status       TINYINT NOT NULL DEFAULT 0 COMMENT '0待支付 1已支付 2已发货 3已取消 4售后中 5已完成',
  total_amount DECIMAL(10,2) NOT NULL DEFAULT 0,
  pay_amount   DECIMAL(10,2) NOT NULL DEFAULT 0,
  created_at   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE order_items (
  id           BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  order_id     BIGINT UNSIGNED NOT NULL,
  product_id   BIGINT UNSIGNED NOT NULL,
  product_name VARCHAR(200) NOT NULL,
  price        DECIMAL(10,2) NOT NULL DEFAULT 0,
  quantity     INT NOT NULL DEFAULT 1,
  subtotal     DECIMAL(10,2) NOT NULL DEFAULT 0
);

CREATE TABLE logistics (
  id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  order_id    BIGINT UNSIGNED NOT NULL,
  company     VARCHAR(50)  DEFAULT NULL COMMENT '快递公司',
  tracking_no VARCHAR(64)  DEFAULT NULL COMMENT '快递单号',
  status      TINYINT NOT NULL DEFAULT 0 COMMENT '0未入库 1运输中 2已签收',
  updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE after_sales (
  id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  order_id    BIGINT UNSIGNED NOT NULL,
  user_id     BIGINT UNSIGNED NOT NULL,
  type        TINYINT NOT NULL COMMENT '1质量问题 2退货 3换货 4维修',
  description TEXT,
  status      TINYINT NOT NULL DEFAULT 0 COMMENT '0待处理 1处理中 2已完成 3已拒绝',
  created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE products (
  id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  name        VARCHAR(200) NOT NULL,
  category_id BIGINT UNSIGNED DEFAULT NULL,
  price       DECIMAL(10,2) NOT NULL DEFAULT 0,
  stock       INT NOT NULL DEFAULT 0
);

CREATE TABLE categories (
  id        BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  name      VARCHAR(50) NOT NULL,
  parent_id BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '0=顶级分类'
);
```

**准备至少一条演示数据**，否则查询永远是空：

```sql
INSERT INTO users (email, name) VALUES ('you@qq.com', '陈');
INSERT INTO orders (order_id, user_id, status, total_amount, pay_amount, created_at)
  VALUES (1, 1, 4, 20.00, 20.00, NOW() - INTERVAL 34 DAY);
INSERT INTO logistics (order_id, company, tracking_no, status, updated_at)
  VALUES (1, '顺丰速运', 'SF1234567890', 2, NOW() - INTERVAL 34 DAY);
```

### 2. PostgreSQL（Checkpointer + 会话摘要）

`POSTGRESQL_URL` 里的库需要先建好（表由代码自动创建）。

LangGraph 的 checkpoint 表**需要初始化一次**。`app/main.py` 里这一行目前是注释掉的：

```python
# await saver.setup()  # 幂等，首次会建表
```

第一次运行前，把它**取消注释**跑一次，或者手动执行：

```python
import asyncio, os
from dotenv import load_dotenv
from langgraph.checkpoint.postgres.aio import AsyncPostgresSaver

load_dotenv()

async def main():
    async with AsyncPostgresSaver.from_conn_string(os.getenv("POSTGRESQL_URL")) as saver:
        await saver.setup()

asyncio.run(main())
```

会话摘要表 `customer_conversation_summary` 由代码在首次使用时自动建。

> **Windows 注意**：psycopg 3 不支持 Proactor 事件循环。自己写脚本测试时记得
> `asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())`，
> `app/main.py` 已经处理好了。

### 3. Redis

不需要建表，但要能连上。存三类 key：

| key | 说明 |
|---|---|
| `session:<uuid>` | 会话表（24 小时过期） |
| `lock:session:<id>` | 会话锁（防止同一会话并发） |
| `customer_window:<id>` | 窗口记忆（条数由 `WINDOW_MEMORY_ROUNDS` 控制） |
| `customer_profile:<id>` | 用户画像 |

如果需要密码，填 `REDIS_PASSWORD`；`REDIS_URL` 也要带上密码：`redis://:密码@localhost:6379/0`。

### 4. ChromaDB（长期记忆）

**不需要手动准备**。`CHROMA_PATH` 指向的目录会自动创建，
集合名 `customer_long_memory` 也是代码里 `get_or_create_collection` 建的。

### 5. 模型

**云端（必需）**：阿里云百炼 DashScope，OpenAI 兼容模式。

1. 在 <https://bailian.console.aliyun.com/> 开通并创建 API Key
2. 把 key 填到 `DASHSCOPE_API_KEY`
3. `OPENAI_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1`
4. `MODEL_LINE_NAME=qwen-plus`（或 `qwen-max` / `qwen-turbo`）

> 同一个 Key 还用于支付宝 MCP 鉴权（`Authorization: Bearer ${DASHSCOPE_API_KEY}`）。

**本地（可选）**：装 [Ollama](https://ollama.com/) 后 `ollama pull qwen2.5:7b`，
配好 `LOCAL_URL` 和 `MODEL_LOCAL_NAME`。
不装也没关系，代码在本地不可用时会自动走云端（聊天节点是云端优先）。

**向量模型（政策 RAG 用）**：需要一个本地 BGE 模型目录，填 `EMBEDDING_MODEL_PATH`。

```bash
# 方式一：HuggingFace 下载（国内可能需要镜像）
pip install -U huggingface_hub
huggingface-cli download BAAI/bge-small-zh-v1.5 --local-dir D:/models/bge-small-zh-v1.5
```

不填这个变量，政策检索会在首次使用时抛错（不再静默降级）。

### 6. 邮件（可选）

只在 `/login` 发验证码时用。QQ 邮箱需要在设置里开启 SMTP 并获取**授权码**，
`EMAIL_PASSWORD` 填授权码而不是 QQ 密码。

## 三、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报 `PoolTimeout` / `ProactorEventLoop` | 用了 Proactor 事件循环 | 用 `run.bat` 启动（`main.py` 里已切 Selector）；自己写脚本要设 policy |
| 意图识别全部变 `unknown`，日志有 `创建云端模型 agent 失败` | `DASHSCOPE_API_KEY` 没读到 | 检查 `.env` 是否在项目根目录，或环境变量是否生效 |
| 聊天回复为空 | 云端 Key 无效 + 本地 Ollama 没开 | 两个至少通一个 |
| SQL 报 `Unknown column 1054` | 表列名和代码预期不一致 | 对照上面的 DDL 补齐列名 |
| 政策咨询答"知识库未覆盖" | `data/policies/after_sales_policy.md` 缺失 | 确认该文件存在（它随仓库提交） |
| 退款报"交易不存在" | 那笔交易没付过款 | 支付宝退款要求原交易真实付款 |
| `data/alipay_records.db` 想重置 | 里面是历史交易记录 | 直接删掉，程序会自动重建 |
